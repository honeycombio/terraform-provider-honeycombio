# Resource: honeycombio_group_grants

Manages all the grants of a Group, to Datasets and to Environments.
The members of the Group can read each Dataset in `dataset_ids`, and every Dataset in each Environment in `environment_ids`.

-> This feature is available as part of the [Honeycomb Enterprise plan](https://www.honeycomb.io/pricing/).

-> This resource requires the provider be configured with a Management Key with `groups:write` and `environments:read` in the configured scopes.

This resource is authoritative: it owns the Group's whole list of grants.

* Set at least one of `dataset_ids` and `environment_ids`. If you leave one out, the Group has no grants of that kind.
* Grants that are not in `dataset_ids` or `environment_ids` are revoked on the next apply, including grants made in the UI.
* Deleting this resource revokes every grant of the Group. The Group itself stays.
* Creating this resource fails for a Group that already has grants. Import the grants instead. The next plan then shows how they differ from the configuration.
* Each Dataset must be restricted. A grant on a Dataset that is not restricted fails. An Environment does not have to be restricted.
* A Dataset in a restricted Environment cannot be granted, and the apply fails. Grant the Environment instead.
* A change of more than 100 grants takes several API requests, so it can stop halfway.
  If an update stops, the next plan shows the grants that are left to change.
  If a create stops, import the Group's grants.

~> **Note** Use one style per Group: `honeycombio_group_grants` or `honeycombio_group_grant`, never both.
  If a Group has both, this resource revokes the single grants, and the single grants create them again on the next apply.

To manage one grant at a time and keep grants made outside Terraform, use `honeycombio_group_grant` instead.

## Example Usage

### Datasets

```terraform
data "honeycombio_auth_metadata" "current" {}

locals {
  payments_datasets = toset(["checkout", "billing", "refunds"])
}

# Turns each slug into the Dataset's ID
data "honeycombio_dataset" "payments" {
  for_each = local.payments_datasets
  slug     = each.key
}

resource "honeycombio_dataset_restriction" "payments" {
  for_each       = data.honeycombio_dataset.payments
  environment_id = data.honeycombio_auth_metadata.current.environment.id
  dataset_id     = each.value.hcid
}

resource "honeycombio_group" "payments" {
  name = "payments-oncall"
}

# The references to the restrictions make Terraform restrict the Datasets
# before it grants them.
resource "honeycombio_group_grants" "payments" {
  group_id    = honeycombio_group.payments.id
  dataset_ids = [for r in honeycombio_dataset_restriction.payments : r.dataset_id]
}
```

### Environments

```terraform
resource "honeycombio_group" "sre" {
  name = "sre"
}

# the plan fails if a name matches no Environment
data "honeycombio_environment" "prod" {
  for_each = toset(["prod-us", "prod-eu"])

  detail_filter {
    name  = "name"
    value = each.value
  }
}

# the Group has no Dataset grants, because dataset_ids is not set
resource "honeycombio_group_grants" "sre" {
  group_id        = honeycombio_group.sre.id
  environment_ids = [for e in data.honeycombio_environment.prod : e.id]
}
```

## Schema

### Required

- `group_id` (String) The ID of the Group whose grants to manage.

### Optional

- `dataset_ids` (Set of String) The unique IDs of every Dataset that the Group can read. Each is the `hcid` of the `honeycombio_dataset` resource and data source, not the Dataset's slug. Each Dataset must be restricted. Without this argument, the Group has no Dataset grants.
- `environment_ids` (Set of String) The IDs of every Environment whose Datasets the Group can read. Each is the `id` of the `honeycombio_environment` resource and data source, not the Environment's slug. Without this argument, the Group has no Environment grants.

### Read-Only

- `id` (String) The ID of the Group.

## Import

A Group's grants can be imported by the Group's ID. e.g.

```
$ terraform import honeycombio_group_grants.payments hcxgr_01jbr2v3k8m4n5p6q7r8s9t0vw
```
