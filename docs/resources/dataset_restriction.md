# Resource: honeycombio_dataset_restriction

Restricts a Dataset.
Only Team owners and the members of a Group that has access to the Dataset can read a restricted Dataset.

-> This feature is available as part of the [Honeycomb Enterprise plan](https://www.honeycomb.io/pricing/).

-> This resource requires the provider be configured with a Management Key with `environments:write` in the configured scopes.
  To delete the restriction of a Dataset that a Group has access to, the key also needs `groups:write`.

The Dataset is restricted while this resource exists.

* Creating this resource fails for a Dataset that is already restricted. Import the restriction instead.
* If the restriction is removed outside Terraform, the next apply restricts the Dataset again.
* A Dataset in a restricted Environment cannot be restricted, and the apply fails.
  When the Environment becomes restricted, the API also clears the restriction of each Dataset in it. See `honeycombio_environment_restriction`.

~> **Warning** Deleting this resource makes the Dataset readable by every Team member again.
  It also removes the Dataset from every Group that has access to it, including access given outside Terraform.
  Restricting the Dataset again does not restore that access.

To keep a Dataset restricted, add `prevent_destroy` to the resource's `lifecycle` block.

When one apply deletes a Dataset together with its restriction, Terraform deletes the restriction first.
If the Dataset's delete then fails, the Dataset stays, without its restriction.

## Example Usage

### With the Environment of the provider's API key

`honeycombio_auth_metadata` returns the ID of the Environment that the provider's API key belongs to.

```terraform
# The Environment of the provider's API key
data "honeycombio_auth_metadata" "current" {}

resource "honeycombio_dataset" "checkout" {
  name = "checkout"
}

resource "honeycombio_dataset_restriction" "checkout" {
  environment_id = data.honeycombio_auth_metadata.current.environment.id
  dataset_id     = honeycombio_dataset.checkout.hcid
}
```

### With the slugs of the Environment and the Dataset

The data sources turn each slug into an ID.
The `honeycombio_dataset` data source reads Datasets in the Environment of the provider's API key.

```terraform
# The Environment that holds the Dataset
data "honeycombio_environment" "prod" {
  detail_filter {
    name  = "slug"
    value = "prod"
  }
}

# A Dataset that Terraform does not manage
data "honeycombio_dataset" "billing" {
  slug = "billing"
}

resource "honeycombio_dataset_restriction" "billing" {
  environment_id = data.honeycombio_environment.prod.id
  dataset_id     = data.honeycombio_dataset.billing.hcid
}
```

### Several Datasets

`for_each` makes one restriction for each slug.
The slugs are the keys, so removing a slug from the set removes only the restriction of that Dataset.

```terraform
# The Environment of the provider's API key
data "honeycombio_auth_metadata" "current" {}

locals {
  payments_datasets = toset(["checkout", "billing", "refunds"])
}

# Turns each slug into the Dataset's ID
data "honeycombio_dataset" "payments" {
  for_each = local.payments_datasets
  slug     = each.key
}

resource "honeycombio_dataset_restriction" "payments" {
  for_each       = data.honeycombio_dataset.payments
  environment_id = data.honeycombio_auth_metadata.current.environment.id
  dataset_id     = each.value.hcid
}
```

## Schema

### Required

- `dataset_id` (String) The unique ID of the Dataset to restrict. It is the `hcid` of the `honeycombio_dataset` resource and data source, not the Dataset's slug.
- `environment_id` (String) The ID of the Environment that holds the Dataset.

### Read-Only

- `id` (String) The ID of the restriction, written as `<environment_id>/<dataset_id>`.

## Import

Dataset Restrictions can be imported by the ID of the Environment and the ID of the Dataset, separated by a `/`. e.g.

```
$ terraform import honeycombio_dataset_restriction.checkout hcaen_01j1jrsewaha3m0z6fwffpcrxg/hcads_01jbr4k2m7n8p9q0r1s2t3v4wx
```

The import fails for a Dataset that is not restricted.
